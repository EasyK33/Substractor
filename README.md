# Substractor

**Substractor** — это удобная desktop-утилита для парсинга, фильтрации и тестирования прокси-подписок. Программа написана на Python и обладает современным графическим интерфейсом на базе CustomTkinter.

Главная цель утилиты — автоматизировать рутинный процесс извлечения рабочих узлов из сырых ссылок-подписок, отсеять нерабочие сервера с помощью пинга и выдать чистые конфигурации.

## 🚀 Основной функционал

* **Многоформатный парсинг:** Поддержка и обработка подписок VLESS, HY, HY2, QWDTT, WDTT, FreeTurn и другие.
* **Тестирование доступности (Ping Test):** Встроенная автоматическая проверка серверов на отклик (ping). Нерабочие сервера можно легко отфильтровать.
* **Удобный экспорт:** Выгрузка отфильтрованных и рабочих конфигураций в чистом текстовом виде или в структурированном JSON-формате для импорта в клиенты (Sing-box, v2ray, Xray).
* **Автоматическое сохранение:** Программа сама запоминает историю введенных URL-адресов (`history_urls.json`) и ваши личные параметры (`settings.json`). При следующем запуске всё будет под рукой.
* **Современный GUI:** Отзывчивый и приятный интерфейс (CustomTkinter).

## 📦 Установка и запуск

### Готовый EXE-файл
1. Перейдите в раздел **Releases** на панели справа.
2. Скачайте файл `Substractor.exe` из последнего релиза.
3. Поместите его в удобную пустую папку и запустите. (Программа автоматически создаст файлы настроек рядом с собой).
